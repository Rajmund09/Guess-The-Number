# Guess The Number | Premium Web Edition

A polished browser-based number guessing game with premium UI, smooth feedback, and a lightweight Python launcher.

## Run It
1. Run `python main.py`
2. Open the local URL shown in the terminal if your browser does not open automatically
3. Guess a number between `0` and `100`
4. Use the live range, smart hint, and history panel to narrow in faster

## Features
- Responsive glass-style web UI
- Live range visualization
- Guess history with proximity feedback
- Smart hints based on the remaining search space
- Best score and rounds-won tracking
- Win-state confetti and toast feedback
- Zero-dependency Python local server

## Project Structure
- `main.py` launches the local web server
- `index.html` contains the app structure
- `styles.css` handles the premium UI styling and motion
- `script.js` powers gameplay and interaction logic
